# Portfólio — Lorraine

Portfólio de design com apresentação pessoal, cases de produto e uma galeria de explorações visuais.

## Estrutura

- `index.html`: páginas, conteúdo e navegação do portfólio.
- `assets/reliquary/`: estilos, scripts e elementos visuais.
- `assets/case-screens/`: imagens dos cases.
- `assets/extras/`: capas e imagens das coleções.
- `assets/stickers/`: adesivos e ilustrações usados no site.

## Visualização local

O site usa HTML, CSS e JavaScript, sem etapa de compilação. Na pasta do projeto, execute:

```sh
python3 -m http.server 8000
```

Depois, acesse `http://localhost:8000` no navegador.

## Atualizações

Edite os arquivos desta pasta e envie as alterações para a branch `main`.

As imagens e os projetos apresentados mantêm os direitos de seus respectivos autores e marcas.
